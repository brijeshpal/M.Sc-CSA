## About the Program

M.Sc. Computational Science and Applications is an interdisciplinary program that combines **computer science, mathematics and statistics**. Students take a common core in the first year, then choose electives in the second year that lead to a specialization in **Data Science**, **Signal Processing** or **Software Engineering**.

## Specializations

A specialization is awarded based on the electives chosen in Semesters III and IV.

| Specialization | Semester III electives | Semester IV electives |
|----------------|------------------------|-----------------------|
| **Data Science** | CSA309, CSA310 | Any three of CSA405–CSA410 (HPC, Longitudinal Data Analysis, Big Data Analytics, Advanced ML, Statistical Data Mining-II, Deep Learning for NLP) |
| **Signal Processing** | CSA311, CSA312 | CSA411, CSA412, CSA413 (Pattern Recognition, Inverse Problems, Image Analysis and Computer Vision) |
| **Software Engineering** | CSA313, CSA314 | CSA414, CSA415, CSA416 (Software Testing, Software Project Management, Software Dependability and Security) |

The fourth Semester IV elective can be any course of the student's choice.

## Evaluation Scheme

- **Theory papers:** 100 marks each, with 70 for the end-semester exam (3 hours) and 30 for sessionals, class tests, seminars and group discussions.
- **Practical papers:** 100 marks each, with 70 for the end-semester practical exam and 30 for sessionals.
- **Dissertation:** evaluated by an internal and an external examiner, with 60 marks for the written report and 40 marks for the presentation and viva.

## Dissertation

**Analyzing the Long-Term Temperature Trends of the Varanasi Region: A Study from 1951 to 2021**

Analysis of 71 years of daily temperature data from the Department of Geophysics, BHU, using data preprocessing, exploratory data analysis, time-series analysis (SARIMA) and machine learning models.

🔗 [View the dissertation project repository](https://github.com/brijeshpal/Analyzing_the_Long_Term_Temperature_Trends_of_the_Varanasi_Region-_A_Study_from_1951_to_2021)
